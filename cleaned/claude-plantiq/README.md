# PlantIQ — claude-plantiq rebuild

AI assistant for South-Indian coffee farmers: photograph a leaf to detect disease (ResNet-50), get a
grounded treatment advisory (hybrid RAG + LLM) that accounts for live microclimate, chat in English or
Kannada (with voice), and buy/sell coffee lots in a local marketplace.
